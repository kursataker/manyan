# TLC's regression suite

Models from TLC's own test suite (`tlatools/org.lamport.tlatools/test-model/suite`
in [tlaplus/tlaplus](https://github.com/tlaplus/tlaplus) v1.7.4, MIT license),
each joined with its configuration and blessed by TLC 2.19. Models whose
output TLC does not reproduce from run to run were left out.
